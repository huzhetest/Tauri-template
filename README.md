# Tauri-template

A clean Tauri v2 + React + TypeScript + Vite desktop app template.

## Development

```powershell
npm install
npm run tauri:dev
```

## Build

```powershell
npm run build
npm run tauri:build
```

## Windows Packages

```powershell
npm run tauri:build:windows
npm run tauri:package:windows
```

The portable zip is written to `dist/tauri-template-v<version>-windows-x64.zip`.
